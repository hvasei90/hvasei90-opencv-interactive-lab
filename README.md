# OpenCV Interactive Lab

یک محیط ارائه فارسی، راست‌چین و تعاملی با اجرای واقعی OpenCV در Python و رابط HTML/CSS/JavaScript.

## راه‌اندازی

نیازمند Python 3.10 یا جدیدتر:

```bash
cd opencv_interactive_lab
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

مرورگر: http://127.0.0.1:8000

## نحوه ارائه

- ورود از صفحه آغازین، انتخاب سرفصل از منو، یا کلیدهای جهت‌دار برای درس قبل/بعد.
- برای رسم دو نقطه را با کلیک روی تصویر انتخاب کنید؛ مختصات با ابعاد اصلی تطبیق داده می‌شود.
- دکمه اجرا، پارامترها و کد اجرایی را هم‌زمان به‌روز می‌کند؛ دکمه پاک کردن نتیجه و نقاط را حذف می‌کند.
- کلید Space: اجرا / پاک کردن.
- تصویر نمونه یا تصویر شخصی؛ دانلود نتیجه در PNG.
- برای موضوعات فیلتر، لبه و مورفولوژی: «مقایسه روش‌ها» خروجی‌ها را روی یک تصویر یکسان محاسبه می‌کند.

## شفافیت فنی

این نسخه، **یک نمونه اجرایی گسترده** است، نه پوشش کامل تمام سرفصل‌های پروژه بزرگ اولیه. درس‌های تئوری و بیش از ۴۰ عملیات واقعی OpenCV دارد. بخش‌های NumPy و Pillow عمداً به‌صورت درس جداگانه اضافه نشده‌اند؛ NumPy فقط برای ساخت آرایه لازم در موتور OpenCV استفاده می‌شود.

- ویدئوی زنده و وب‌کم / VideoWriter در این نسخه به‌صورت تئوری معرفی شده‌اند؛ دموهای واقعی آنها هنوز ساخته نشده‌اند.
- YOLO و Ultralytics عمداً نصب یا شبیه‌سازی نشده‌اند و دمو در این نسخه وجود ندارد.
- SURF وابسته به بیلد nonfree OpenCV است و به‌جای خطای خام، پیام محدودیت نمایش داده می‌شود.
- imshow / waitKey / destroyAllWindows مربوط به پنجره دسکتاپ OpenCV هستند؛ رابط مرورگر رویدادهای خودش را دارد و صادقانه به‌عنوان جایگزین معرفی می‌شود.
- نمایش رنگ‌های HSV/HLS و RGB پس از تبدیل معکوس به BGR انجام می‌شود. برای دیدن کانال‌ها از split و برای جداسازی رنگ از inRange استفاده کنید.
- کد قابل مشاهده، **همان دستورات اصلی پردازش** است که سرور با exec اجرا می‌کند. رمزگشایی فایل ورودی (cv2.imdecode) و رمزگذاری تصویر خروجی (cv2.imencode) در لایه API هستند، نه در کد درس.
- `filter2D` مطابق OpenCV همبستگی (Correlation) انجام می‌دهد، نه کانولوشن ریاضی با معکوس‌کردن kernel.

## ساختار

- `main.py`: FastAPI، پردازش تصویر، تولید کد و API هیستوگرام.
- `static/index.html`: اسکلت محیط ارائه.
- `static/style.css`: طراحی راست‌چین Responsive.
- `static/app.js`: محتوا، کنترل‌ها، نمایش و رویدادهای تعاملی.

## محدودیت‌های ایمنی

آپلود فایل به‌صورت Base64 با محدودیت اندازه پردازش می‌شود. کد تولیدی از لیست سفید دستورات و مقادیر اعتبارسنجی‌شده ساخته می‌شود؛ برنامه نباید بدون احراز هویت و محدودسازی مصرف منابع روی اینترنت عمومی منتشر شود. در حالت محلی اجرا کنید.


## نسخه 1.1: مباحث تکمیلی

- مفاهیم آغازین: تصویر دیجیتال، رزولوشن، کانال‌های رنگی، فرمت‌ها و مراحل پردازش تصویر
- NumPy: ابعاد و نوع آرایه، مشاهده و تغییر پیکسل، برش، کانال‌ها، where، clip، flip، rot90، آمار و reshape
- Pandas: DataFrame از پیکسل‌ها، head، describe، groupby و histogram/value_counts با جدول واقعی
- برای دروس تحلیل داده، جدول زیر کد به صورت خودکار از داده‌های واقعی تصویر ساخته می‌شود.

### اجرا در ویندوز

ابتدا در PowerShell پوشه پروژه را باز کنید و این دستور را اجرا کنید:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

سپس http://127.0.0.1:8000 را باز کنید. همچنین می‌توانید پس از نصب پیش‌نیازها فایل `start_windows.bat` را اجرا کنید.

**توجه:** نام فایل اصلی این نسخه `main.py` است، نه `app.py`.
